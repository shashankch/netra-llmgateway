# NETRA Product Roadmap

This document outlines the phased engineering milestones for NETRA. Milestones follow standard delivery stages: `Complete`, `In Progress`, and `Scheduled`.

---

## Phase Milestones

| Phase | Target Release | Milestone Name | Status | Key Deliverables |
|---|---|---|---|---|
| **Phase 1** | `v0.1.0` | Foundation & Ingress Pipeline | Complete | Java 25 LTS baseline, Spring Boot 4.1.1, Docker Compose stack, canonical data seeder, strict `x-netra-*` telemetry contract, OpenAPI 3.1 specification (`openapi.yaml`). |
| **Phase 2** | `v0.2.0` | Virtual Key Auth & Atomic Admission | Complete | Multi-tenant auth, model allowlists, atomic Redis 8.0 Lua sliding-window rate limiting, zero over-admission guarantee, monthly budget caps, request audit logs. |
| **Phase 3** | `v0.3.0` | Unbuffered Streaming SSE Relay | Complete | Token-by-token pass-through streaming over Server-Sent Events on Java 25 Virtual Threads, terminal chunk usage extraction, mid-stream disconnect handling. |
| **Phase 4** | `v0.4.0` | Multi-Provider Routing & Auto Classifier | Complete | Ordered fallback chains (primary + fallbacks), exponential backoff retries (3 attempts), fast-failover across providers, two-stage prompt difficulty classifier for `auto` tier achieving 100% accuracy on `data/routing_eval.jsonl`, and `x-netra-route-reason` / `x-netra-retries` telemetry headers. |
| **Phase 5** | `v0.5.0` | Tenant-Isolated Semantic Vector Cache | Complete | In-JVM dense embeddings via quantized `all-MiniLM-L6-v2` (384-dim), PostgreSQL 18 `pgvector` HNSW index (`<=>` cosine distance), strict per-tenant cryptographic isolation, paraphrase matching, near-miss rejection, refusal suppression, multi-turn context keying, streaming SSE cache replay, and `GET /admin/cache/stats`. |
| **Phase 6** | `v0.6.0` | Ops Console & Enterprise Verification Suite v2 | Complete | React 19 / Vite 6 Ops Console (`dashboard/`), OpenRouter-grade analytics KPIs, single-denomination forex toggle (USD/INR), live SSE request stream, virtual key manager, prompt playground with 1-click demo profiles, multi-tier PaaS deployment blueprints (Railway, Render, Fly.io, Vercel, OCI/AWS VPS), Enterprise v2 Verification Suite (`scripts/v2/stress_test.py` for TPS/TTFT latency curves, `scripts/v2/chaos_drill.py` for socket abort drills, and `scripts/v2/cache_fuzzer.py` for adversarial refusal & cross-tenant leak probes), and comprehensive E2E verification report (`docs/verification-report.md`). |
| **Phase 7** | `v0.7.0` | Resilience, Two-Tier Cache & Protocols | In Progress | Two-tier cache hierarchy (Tier-1 exact SHA-256 hash <0.5ms + Tier-2 pgvector semantic cache), IETF standard RateLimit headers (`RateLimit-Limit`, `Remaining`, `Reset`, `Retry-After`), Resilience4j dynamic circuit breakers & provider health telemetry (`GET /admin/providers/health`), small-model refusal auto-escalation engine, and dedicated Ops Console visual gauges (Phantom Spend Reclaim & Socket Abort Velocity Gauge, Cosine Boundary & Near-Miss Defense Distribution Plot, Live Provider Health Explorer). |
| **Phase 8** | `v0.8.0` | Automated CI Chaos Pipelines & OTel Observability | Scheduled | Continuous automated synthetic chaos pipelines in GitHub Actions CI, Model Playground A/B side-by-side comparison view, provider-side prompt caching discount tracking (`cached_tokens`), OpenTelemetry GenAI semantic conventions, HikariCP connection protection via bounded asynchronous audit log batching, and Java 25 Scoped Values context propagation. |
| **Phase 9** | `v0.9.0` | Enterprise Security, Guardrails & Token Vault | Scheduled | Real-time AI safety & PII DLP guardrails (regex/Luhn detection with tenant-level mask/block toggles), cryptographic virtual key vault (salted SHA-256 with legacy seed compatibility), RBAC with HMAC-signed audit logs, and formal OWASP Top 10 for LLM Applications (2025/2026) compliance. |
| **Phase 10** | `v1.0.0` | Multi-Region Scalability, Cloud Deploy & Metered Billing | Scheduled | Production Kubernetes Helm charts, Terraform IaC (AWS ECS + RDS / OCI Always Free), dual-gateway self-recharge & metered billing (Stripe card invoicing + Indian UPI / Razorpay AutoPay e-mandates), and modular event-driven decoupling. |
